# Wiki markup checklist

Based on [MediaWiki formatting](https://www.mediawiki.org/wiki/Help:Formatting) and [links](https://www.mediawiki.org/wiki/Help:Links) documentation.

## Core formatting

- [x] Italic: `''text''`
- [x] Bold: `'''text'''`
- [x] Bold and italic: `'''''text'''''`
- [x] Headings, levels 2–6: `== Heading ==`
- [x] Paragraphs separated by blank lines; single line breaks within paragraphs
- [x] Explicit line break: `<br />`
- [x] Horizontal rule: `----`
- [x] Literal text that bypasses markup: `<nowiki>…</nowiki>`

## Lists

- [x] Bulleted lists: `* item`
- [x] Numbered lists: `# item`
- [x] Nested and mixed lists: `**`, `##`, `#*`, and similar combinations
- [x] Description lists: `; term` and `: definition`

## Links

- [x] Internal link: `[[Main Page]]`
- [x] Internal link with a label: `[[Main Page|Home]]`
- [x] Links to sections: `[[Main Page#Section]]`
- [x] External links, including labeled links: `[https://example.com Label]`
- [x] Links to missing pages lead to the create-page screen

## Additional formatting

- [x] Preformatted text using a leading space or `<pre>…</pre>`
- [x] Inline code: `<code>…</code>`
- [x] Underline and strikethrough: `<u>`, `<ins>`, `<s>`, and `<del>`
- [x] Blockquotes and inline quotations: `<blockquote>` and `<q>`
- [x] Comments hidden from the rendered page: `<!-- comment -->`
- [x] Character references such as `&mdash;`
- [x] Table of contents for pages with four or more headings, with `__NOTOC__` to suppress it

The formatting documentation also links to separate references for images, tables, citations and other features.
